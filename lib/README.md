# Složka `lib`

Složka `lib` je určena pro externí knihovny. Jelikož obsahuje knihovny s vlastními licencemi, nesynchronizuje se s úložištěm a jednotlivé knihovny je potřeba instalovat individuálně.

Momentálně aplikace používá pouze knihovnu `Saxon-HE`.

## Instalace Saxon-HE

1. Stáhněte Saxon-HE 12.9 z: <https://github.com/Saxonica/Saxon-HE/releases/download/SaxonHE12-9/SaxonHE12-9J.zip>
2. Umístěte soubor `saxon-he-12.9.jar` a jeho podsložku `lib` do adresáře `lib/`
