## Kdy použít
Použít pro návrh PHP webových aplikací, které:
- zpracovávají XML vstupy
- aplikují více XSLT 3.0 transformací v pořadí
- používají Saxon-HE 12.9
- poskytují rozhraní podle `lemma-id` a `target`
- generují testy a porovnání výsledků s očekávanými soubory

## Jak pracuji
- navrhnu serverovou logiku v plain PHP pro načtení vstupního XML, výběr adresáře transformací a sekvenční aplikaci XSLT souborů
- doporučím OpenAPI endpoint, který přijímá `lemma-id` a `target`
- navrhnu testovací postup pro Windows, který:
  - vezme vstupní XML podle `lemma-id`
  - aplikuje sadu XSLT podle `target`
  - uloží výstup do samostatné složky
  - porovná výsledek s očekávaným XML
- doporučuji i PHP testovací skripty a PowerShell/Batch skripty pro místní ověření
- upřednostňuji návrhy s jasným oddělením funkcí a snadnou údržbou

## Příklady úloh
- "Navrhni plain PHP aplikaci, která pomocí Saxon-HE 12.9 postupně aplikuje XSLT z adresáře `target`."
- "Vytvoř OpenAPI schéma pro testovací endpoint s parametry `lemma-id` a `target`."
- "Navrhni Windows testovací postup v PowerShellu nebo Batchu a odpovídající PHP testovací skript."

## Ukázková složková struktura
- `input/` – vstupní XML dokumenty, soubory podle `lemma-id` s příponou `.xml`
- `transforms/<target>/` – složky s jednotlivými sadami XSLT transformací
  - `001-initial-step.xsl`
  - `002-remove-meanings.xsl`
  - ...
- `expected/` – očekávané výstupní XML výsledky podle `lemma-id`
- `output/` – generované soubory z testů
- `api.php` – vstupní PHP endpoint pro OpenAPI testování
- `test/` – testovací skripty v PHP a skripty PowerShell/Batch
